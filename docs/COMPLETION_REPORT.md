# LobStars — Финальный Отчёт

## Краткое описание проекта

**LobStars** — это музыкальный плеер нового поколения, где встречаются три роли:
- **Дизайнеры** создают и продают скины (темы оформления) плеера
- **Музыканты** загружают треки и прикрепляют к ним скины для промо
- **Слушатели** поддерживают авторов виртуальными звёздами и получают эксклюзивные скины

Платформа работает на **виртуальных звёздах** (game currency, не реальные деньги). Это demo-прототип, показывающий концепцию marketplace для дизайнеров и музыкантов.

## Что содержит прототип

### 1. Система скинов (в прототипе)

**12 встроенных тематических скинов:**

1. **Стандартный** (default)
   - Чистый нейтральный дизайн
   - Активен по умолчанию для всех новых пользователей
   - Всегда бесплатен, первый в списке
   - Одним тапом сбрасывает тематическое оформление

2. **Классический Spotify** — зелёные акценты, круглые кнопки
3. **Неоновая Ночь** — киберпанк, неоновые контуры, gradient-blobs анимация
4. **Космос** — фиолетовые звёздные оттенки, particles анимация
5. **Закат** — оранжево-розовые тона, pill кнопки, gradient-blobs
6. **Ретро Волны** — синтвейв, waveform анимация
7. **Минимализм** — монохром, минималистичные кнопки
8. **Броня гения** — красно-золотой tech HUD (Iron Man-inspired, без товарных знаков)
9. **Ночной паутинщик** — красно-синий город (Spider-Man-inspired, без товарных знаков)
10. **Бейкер-стрит** — викторианский детектив (Sherlock Holmes-inspired)
11. **Викинги** — северные фьорды, драккары (Vikings series-inspired, без товарных знаков)
12. **Железный трон** — средневековый замок (Game of Thrones-inspired, без товарных знаков)

**Загрузка своего фото:**
- Пользователь загружает изображение с телефона (capture="environment" для камеры)
- Сервер автоматически обрабатывает (Pillow):
  * Исправляет EXIF-ориентацию
  * Создаёт баннер (1200×400), фон (800×800), миниатюру (300×200)
  * Конвертирует в WebP с оптимизацией
  * Извлекает доминантный и вторичный цвет для акцентов
- Сохраняется как новый скин в библиотеке пользователя

**Мгновенное применение на всех страницах:**
- Главная — баннер в header
- Библиотека — фон карточек
- Плеер (now-playing) — полноэкранный фон
- Мини-плеер — акцентные цвета кнопок
- Страница скинов — превью
- Профиль — фон

**5 стилей кнопок:** round, square, pill, outline, minimal

**4 типа анимаций (no-buttons mode):**
- equalizer — пульсирующий эквалайзер
- waveform — волновая форма
- particles — частицы (звёзды, снег)
- gradient-blobs — плавные градиентные блобы
- Respects `prefers-reduced-motion`

### 2. Библиотека скинов (в прототипе)

**Моя библиотека** включает:
- Preset-скины (бесплатны для всех)
- Купленные скины других дизайнеров (за виртуальные звёзды)
- Собственные скины из загруженных фото

Дизайнер устанавливает цену при публикации. Покупка создаёт entitlement-запись.

### 3. Jamendo интеграция с ротацией и тематическими рекомендациями (в прототипе)

**Ротация треков:**
Каждый визит/refresh показывает **разные треки** вместо одних и тех же:
- Отслеживание показанных треков (DB для авторизованных, localStorage для гостей)
- Варьирующийся offset (seeded by день + user ID)
- Микс популярных (50%) и новых (50%) треков
- Блок **«Новое для вас»** — непоказанные треки (до 40)
- Блок **«Уже слушали»** — ранее показанные треки (до 20) с маркером 🔁
- Кнопка **«Показать другие»** для принудительной ротации

**Тематические рекомендации:**
Каждый скин связан с определёнными жанрами/настроением Jamendo:

| Скин | Теги Jamendo | Fallback |
|------|--------------|----------|
| Стандартный | pop rock indie electronic | pop rock |
| Классический Spotify | pop rock indie electronic | pop rock |
| Неоновая Ночь | electronic synthwave cyberpunk techno | electronic |
| Космос | ambient electronic space soundtrack | ambient electronic |
| Закат | chillout lounge downtempo acoustic | chillout |
| Ретро Волны | synthwave electronic retro 80s | electronic |
| Минимализм | ambient minimal piano classical | ambient |
| Броня гения | rock electronic metal industrial | rock |
| Ночной паутинщик | rock electronic alternative indie | rock |
| Бейкер-стрит | classical jazz acoustic instrumental | jazz |
| Викинги | folk epic ambient soundtrack | folk |
| Железный трон | orchestral cinematic epic soundtrack | orchestral |

При смене скина блок рекомендаций **обновляется автоматически** с соответствующими тегами.

Если основные теги дают мало треков (< limit/2) — автоматический fallback на более широкие теги, о чём сообщается в ответе API.

### 4. Виртуальные звёзды (в прототипе)

**Game currency, не реальные деньги:**
- Каждый новый пользователь получает 100 звёзд при регистрации
- Используются для покупки скинов, поддержки треков, ставок
- Баланс в `user_profiles.stars_balance` (Postgres) или localStorage (гости)

### 5. Загрузка музыки (в прототипе, базовая)

Пользователи могут загружать свои треки (MP3, до 20 МБ). Сервер сохраняет файл в `media/songs/`.

### 6. Связки скин+трек (в прототипе, модель готова)

Модель `TrackSkin` позволяет прикреплять скины к загруженным трекам. При воспроизведении трека показывается прикреплённый скин.

## Что реализовано позже (не в текущем прототипе)

### Стартовое предложение для новых пользователей
Блок с предложением стать первым спонсором свежего/растущего скина или трека.

### Треки: тотализатор
Загрузка трека со ставкой в звёздах. Если трек «выстреливает» — попадает в рекомендации. Спонсоры получают выплаты по формуле:
- Выстрелил (hit): возврат ставки + 50% бонус
- Выгорел (burned): возврат 20% ставки

### Тотализатор для скинов
Аналогично трекам: ставка при публикации, выплаты при «выстреле» или «выгорании».

### Самопродвижение
Музыканты и дизайнеры могут тратить звёзды на продвижение:
- Себя как артиста (profile card)
- Своих скинов
- Своих треков с прикреплёнными скинами
Продвигаемые элементы появляются в полке «Продвигается» на главной.

### Ставки слушателей на контент
Обычный слушатель (не автор) может ставить звёзды на:
- Трек
- Скин
- Связку скин+трек (bundle)

### Реальные платежи

### Чат для сделок

### Платное продвижение
Рекламные слоты, таргетинг, аналитика эффективности.

### Импорт изображений

### Расширенные функции

## Технические детали

### Backend (Python/FastAPI)

**Модели БД:**
- `Skin` — скины оформления (11 preset + пользовательские)
- `SkinEntitlement` — права на использование скинов
- `TrackSupport` — поддержка треков звёздами
- `TrackSkin` — связь треков и скинов (многие-ко-многим)
- `JamendoShown` — отслеживание показанных треков Jamendo (для ротации)
- `Promotion` — продвижение контента (для будущего)
- `Stake` — ставки на контент (для будущего)

**Обработка изображений (Pillow):**
```python
def process_skin_image(image_data: bytes):
    # 1. Fix EXIF orientation
    img = fix_exif_orientation(Image.open(io.BytesIO(image_data)))
    
    # 2. Generate three sizes with center-crop
    banner = resize_and_crop(img, 1200, 400)      # Wide banner
    background = resize_and_crop(img, 800, 800)   # Square bg
    thumbnail = resize_and_crop(img, 300, 200)    # Thumbnail
    
    # 3. Convert to WebP with optimization
    banner_webp = convert_to_webp(banner, quality=85)
    background_webp = convert_to_webp(background, quality=85)
    thumbnail_webp = convert_to_webp(thumbnail, quality=80)
    
    # 4. Extract dominant colors
    dominant = get_dominant_color(img)      # Main accent
    secondary = get_secondary_color(img)    # Secondary accent
    
    return banner_webp, background_webp, thumbnail_webp, dominant, secondary
```

**API endpoints:**
- `GET /api/skins` — маркетплейс (все публичные скины)
- `GET /api/skins/library` — библиотека пользователя

- `POST /api/skins/upload-image` — загрузить и обработать фото
- `POST /api/skins/activate` — применить скин
- `POST /api/skins/purchase` — купить скин за звёзды
- `GET /api/jamendo/discover` — Jamendo с ротацией и темами

## Стилистические заметки по скинам

### Что работает хорошо:

1. **Стандартный** — идеален как default. Нейтральный, не перегружает, позволяет сосредоточиться на музыке.
   
2. **Классический Spotify** — узнаваемая зелёная тема, привычный UX, отличный onboarding для новых пользователей.

3. **Неоновая Ночь** — outline кнопки идеально подходят к киберпанк-эстетике. Gradient-blobs анимация усиливает футуристичность.

4. **Космос** — фиолетовые оттенки + particles создают космическое настроение. Ambient музыка отлично сочетается.

5. **Викинги** — холодные синие тона + folk музыка = сильная тематическая связь. Waveform анимация напоминает морские волны.

6. **Железный трон** — тёмные угольные оттенки + красные акценты = средневековая мрачность. Orchestral музыка идеальна.

### Что стоит улучшить (для beauty & cohesion):

1. **Закат** — оранжево-розовые тона яркие, но могут быть слишком контрастными на тёмном фоне. 
   - **Fix applied:** добавлен полупрозрачный gradient overlay на текст для читаемости.

2. **Минимализм** — белые акценты (#FFFFFF) могут быть слишком резкими на чёрном фоне.
   - **Рекомендация:** использовать #F5F5F5 (off-white) для мягкости. Или добавить subtle shadow.

3. **Броня гения** — красный (#C41E3A) + золотой (#FFD700) — смелое сочетание, но золотой может плохо читаться на светлых элементах.
   - **Fix applied:** добавлен темнее вторичный акцент для текста (#DAA520 darkgoldenrod).

4. **Ночной паутинщик** — красный (#DC143C) + синий (#1E90FF) — комплементарные цвета, высокий контраст. Хорошо для энергии, но может быть резким.
   - **Рекомендация:** снизить насыщенность на 10-15% для комфорта глаз при длительном использовании.

5. **Бейкер-стрит** — коричневый (#8B4513) + тёмно-серый (#2F4F4F) — очень приглушённая палитра. Идеально для детектива, но может быть слишком мрачной.
   - **Рекомендация:** добавить тёплый акцент (например, янтарный #FFBF00) для ламп/огней викторианского Лондона.

6. **Ретро Волны** — розовый (#FF6EC7) + фиолетовый (#7B2CBF) — классический синтвейв. Хорошо, но может конкурировать с обложками альбомов.
   - **Fix applied:** снижена непрозрачность banner до 0.7 для лучшей читаемости контента.

## Как запустить

```bash
# Клонировать репозиторий
git clone <url>
cd <repo>

# Запустить Docker Compose
docker-compose up --build

# Frontend: http://localhost:3000
# Backend: http://localhost:8000
# API Docs: http://localhost:8000/docs
```

### Тестирование с мобильного (Wi-Fi)

```bash
# Узнайте IP компьютера
ipconfig      # Windows
ifconfig      # macOS/Linux

# На телефоне откройте
http://<IP>:3000
```

Пример: `http://192.168.1.100:3000`

**Что протестировать:**
1. Загрузите фото с камеры телефона
2. Создайте свой скин
3. Переключайтесь между скинами — они применяются мгновенно
4. Смотрите Jamendo рекомендации — они меняются вместе со скином
5. Нажмите «Показать другие» — получите новые треки
